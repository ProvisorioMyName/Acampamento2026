# 🏕️ Manual de Acampamento - Igreja

Projeto desenvolvido com o objetivo de criar um **Manual de Acampamento** digital e organizado para a minha igreja. Além de suprir essa necessidade prática da comunidade, estou utilizando este repositório para **aperfeiçoar meus conhecimentos** em desenvolvimento de software, aplicando na prática conceitos de estruturação, design e boas práticas de código.

---

## 🚀 Sobre o Projeto

O propósito deste sistema é centralizar todas as informações essenciais para a realização do acampamento da igreja, facilitando o acesso de líderes, participantes e equipe de organização.
